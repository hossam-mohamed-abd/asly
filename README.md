# ASLY | أصلي TECH STORE — نظام الإدارة ونقطة البيع والصيانة الذكية

منصة متكاملة مبنية بلغة **PHP** مع قاعدة بيانات **MySQL (PDO)** ومصممة للعمل مباشرة على **XAMPP / phpMyAdmin** لمركز **أصلي تك ستور (ASLY TECH STORE)** لبيع وصيانة اللابتوبات والهواتف الذكية والأجهزة القابلة للارتداء والإكسسوارات.

---

## ✨ أهم مميزات النظام

1. **واجهة خارجية فاخرة للعملاء (Landing Page — بدون أي أسعار نهائياً):**
   - هوية بصرية عالمية مستوحاة من بنر المركز الرسمي (**ASLY | أصلي TECH STORE** بألوان الزمرد البترولي والذهبي الملكي).
   - عرض صور ومواصفات المنتجات المتاحة مقسمة (**لابتوب، هواتف، إكسسوارات، أجهزة قابلة للارتداء**) مع فلترة الحالة (**جديد، كسر زيرو، مستعمل**) بدون كشف أي أسعار.
   - زر **«اسأل عن السعر عبر واتساب»** تحت كل منتج برسالة جاهزة تحتوي على اسم المنتج وكوده.
   - بوابة مباشرة لتتبع حالة أجهزة الصيانة عبر كود التذكرة أو مسح الـ QR.
   - قسم تواصل ديناميكي بالكامل يتحكم فيه الأدمن من لوحة التحكم.

2. **نظام الكاميرا والباركود المطاول والـ QR الذكي (جزأين):**
   - **الجزء الأول (إضافة منتج للمخزن):** إمكانية مسح الباركود الطولي (1D Barcode) أو الـ QR بالكاميرا، أو **توليد كود QR وباركود تلقائي بدون مسح** جاهز للطباعة كاستيكر، مع تسجيل الأسعار الثلاثة (**سعر الشراء الحقيقي، سعر البيع، وأقل سعر بيع**).
   - **الجزء الثاني (كاشف السعر السريع أمام العميل):** عند مسح القطعة يظهر **سعر البيع فقط** بخط كبير، وتحته زر **«اعرض سعر الشراء»** الذي يعرض **أقل سعر بيع** تمويهاً أمام العميل مع إخفاء تكلفة الشراء الحقيقية تماماً.

3. **نظام صلاحيات المدير والموظفين + الفواتير كصورة وواتساب وطباعة:**
   - **المدير (Admin):** يرى كافة الأرباح الصافية، سعر الشراء الحقيقي، المبيعات اليومية، إيرادات الصيانة، رأس مال المخزن، ويدير الموظفين والإعدادات.
   - **الموظف (Staff):** يرى فقط **سعر البيع** و**أقل سعر بيع**، ويُصدر فواتير البيع لمنتج واحد أو عدة منتجات مع خصم المخزون تلقائياً، **ومنع برمجي صارم من البيع بأقل من أقل سعر بيع مسموح**.
   - **تصدير الفاتورة:** تحميل الفاتورة كصورة **PNG** عالية الدقة، إرسالها مباشرة عبر **واتساب** للعميل، أو **طباعتها**.

4. **نظام الصيانة التفاعلي بالـ QR + إشعارات البريد الإلكتروني + مسح البيانات عند التسليم:**
   - تسجيل بيانات العميل وهواتفه وإيميله ومواصفات الجهاز وتوليد **إيصال QR خاص بالعميل**.
   - متابعة تفاعلية لـ **7 مراحل صيانة** مع إمكانية كتابة ملاحظات وتعليقات متبادلة على كل مرحلة من الأدمن ومن العميل عبر هاتفه.
   - **إشعارات البريد الإلكتروني (SMTP):** إرسال رسالة HTML تلقائية بتفاصيل كل مرحلة جديدة للعميل في حال تسجيل بريده الإلكتروني.
   - **الحذف التلقائي عند التسليم النهائي:** فور تسليم الجهاز للعميل، يحتفظ النظام **فقط بالمبلغ المدفوع** في جدول إيرادات اليوم، ويمسح نهائياً كافة البيانات الشخصية وتفاصيل وملاحظات الجهاز.

## 🚀 خطوات التشغيل على XAMPP + phpMyAdmin

1. انسخ مجلد المشروع `asly` وضعه داخل مسار `htdocs` في XAMPP:
   ```
   C:\xampp\htdocs\asly
   ```
2. افتح برنامج **XAMPP Control Panel** وشغّل كلاً من **Apache** و **MySQL**.
3. **إعداد قاعدة البيانات (طريقتان سهلتان):**
   - **الطريقة الأولى (تلقائية بضغطة واحدة):** افتح المتصفح على الرابط `http://localhost/asly/install.php` وسيقوم النظام بإنشاء قاعدة البيانات `asly_store` واستيراد الجداول والبيانات الأولية تلقائياً!
   - **الطريقة الثانية (يدوياً عبر phpMyAdmin):** افتح `http://localhost/phpmyadmin` ثم اضغط **Import (استيراد)** واختر الملف `database/asly_store.sql` ثم اضغط **Go**.
4. افتح الموقع ولوحة التحكم:
   - **الواجهة الخارجية للعملاء:** `http://localhost/asly/`
   - **لوحة تحكم الإدارة والموظفين:** `http://localhost/asly/admin/login.php`

## 📱 ملاحظة لفتح كاميرا الموبايل على شبكة الـ Wi-Fi مع XAMPP
متصفحات الهواتف تسمح بفتح الكاميرا تلقائياً على `localhost` أو عبر `HTTPS`. عند فتح الداشبورد من هاتفك عبر شبكة المحل المحلية:
- شغّل Apache مع SSL في XAMPP واستخدم `https://192.168.1.x/asly/admin/` لفتح الكاميرا الحية مباشرة، **أو** استخدم زر **«مسح من صورة باركود»** المدمج بالنظام والذي يفتح كاميرا الهاتف فوراً على أي اتصال HTTP عادي بدون أي إعدادات إضافية.
